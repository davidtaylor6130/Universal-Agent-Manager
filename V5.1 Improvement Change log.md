# V5.1 Improvement Change log

## Poll-tick state rebuild window — 2026-11-05

| Group | Type | Change | Summary | Status |
|---|---|---|---|---|
| Chat and streaming | Performance | Poll-Tick State Rebuild Window | While chats stream, each poll tick rebuilds the state fingerprint at most once per 100 ms summary window and defers other changes inside it (an ordinary chat update can land up to just under 200 ms after that chat's previous update; new pending requests, CLI launches and settings-level slices still rebuild on that tick), so a CLI chat and a structured chat streaming together no longer spend the UI thread re-serialising state on every 16 ms tick; bridge handlers still push immediately. | Implemented ([#362](https://github.com/davidtaylor6130/Universal-Agent-Manager/issues/362)); Claude Reviewed; Not User Tested |
