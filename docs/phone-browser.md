# Phone browser sections

The published browser has Activity, Chats and connection Settings, with its own navigation, project/search filters and refresh state. Activity groups running/needs-input and recent output; opening a chat retains provider/workspace identity, supports the permitted Chat/CLI views and exposes only companion-authorized actions. Connection uses the access token from the main device; browser-local sign-out removes that browser's saved token rather than stopping desktop work. When the computer rotates the token, requests are refused and the page says to log out and connect with the current token instead of retrying. New chat, pinning, sending and terminal input remain real controller actions with ordinary ownership/permission rules. A disconnected or stale page must report its state and must not replay input automatically. A long prompt or other request of 60 KiB or more is uploaded in pieces and committed once, through the same [chunked request upload](reference/companion-protocol.md#chunked-request-envelopes) as the native iPhone client; a failure before the commit reports that nothing was sent (or that the token was rejected, or that the request is too large to upload), and a lost commit reply is reported as unknown rather than retried. Browser storage/home-screen presentation does not turn this into a separately installed native phone app. Agent-published [HTML views](chat/html-views.md) show their title with a view-on-desktop placeholder; the phone browser never loads the page.

[Phone access](phone-access.md) · [Phone settings](settings/phone-access.md) · [Navigation](navigation/navigation.md).

Browser theme, input-alert preferences, clipboard and supported speech recognition belong to the phone browser and do not change the desktop’s settings or use its microphone or clipboard. Optional browser notifications require a secure context and browser permission; they report input requests while the companion is open, and selecting one opens that saved chat locally without sending input. If permission is denied, the ordinary Activity view remains available.
