# Diffs

A diff compares the selected file against its explicit repository baseline or a captured edit patch; it does not automatically mean all changes made by the current chat. Unified and Split views show the same change, with the preferred layout retained locally. Preserve additions, removals, rename and permission metadata; copying returns the underlying patch even when Split presentation omits framing. Loading, failure, binary changes and no textual diff are distinct states. Inspect file opens the current file on the intended host, which may differ from the historical patch. Changing chat, workspace or comparison must not display a stale result as current.
