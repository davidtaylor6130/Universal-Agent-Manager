# Memory

Memory is UAM’s durable store of useful preferences, decisions, facts and lessons, kept separately from ordinary conversation history. Recall supplies relevant bounded context to future work; extraction proposes or records supported durable knowledge under the current policy. User-authored content and workspace ownership must be preserved, and routine progress is not automatically a durable lesson. Memory is different from skills, agent instructions and the provider’s private conversation context.
