# Provider Overview

Overview summarises included provider availability and observed connections for the selected execution environment, with links to each provider's configuration and shared setup. Disabling a provider here is a saved runtime-availability choice, not removal from the built application; [build flags](../build-flags.md) own deliberate compiled exclusion. Show saved enablement separately from CLI presence, version and connection health, retain drafts on failed saves and do not describe a capability as available merely because the provider is enabled.
