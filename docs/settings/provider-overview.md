# Provider Overview

Overview summarises included provider availability and observed connections for the selected execution environment, with links to each provider's configuration and shared setup. Disabling a provider here is a saved runtime-availability choice, not removal from the built application; [build flags](../build-flags.md) own deliberate compiled exclusion. Show saved enablement separately from CLI presence, version and connection health, retain drafts on failed saves and do not describe a capability as available merely because the provider is enabled. Like a build-excluded provider, a provider disabled on a computer appears for that computer only in Settings: New chat, the composer's provider choices, Limits and Updates leave it out, the chat search filter offers it only while chats still use it, and no version sweep, automatic update or new account allowance read starts for it there. An existing chat still shows its own provider. Native New chat, side-chat, regenerating-branch and shell-action creation reject that provider before saving a chat or workspace; automatic routing skips disabled host/provider pairs, and existing chats keep their history while sends stay blocked.
