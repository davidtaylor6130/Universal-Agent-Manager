# About settings

About identifies the running application version and controls automatic update checks. The version must describe the running build, and an enabled check preference must remain distinct from observed connectivity, an available release or completed installation. Manual checks, release information and provider update actions belong to the [Updates surface](../updates/updates.md); turning checks off must not imply that existing installations or provider processes have been removed.
