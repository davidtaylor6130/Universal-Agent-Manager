# Storage and cleanup

Storage settings explain where UAM keeps chats and other local resources and allow deliberate cleanup without treating a cache, a conversation or a user workspace as interchangeable. Preview scope and consequences, preserve active work and report partial cleanup. Cleanup must not silently remove original provider history, unrelated workspace files or resources owned by another chat.
