# Chat Data settings

Chat Data exports saved conversations as a portable bundle into a new or empty folder and imports bundles without overwriting existing chat identities; collisions receive new IDs. Preserve supported history and organisation while reporting skipped or failed items. Imported bundles are passive read-only transcripts until explicit supported reconnection: saved runtime IDs, queued input, goals and remote cleanup metadata must not start work merely because files were imported. Export is not a live transactional backup of running provider processes or every application setting.
