# Display preferences

Display preferences control message width, higher contrast, diff addition/removal colours, model token limits and animation speed. The colour-blind-friendly palette must apply consistently to diffs and reviews; status cannot rely on colour alone. Sidebar provider icons/worktree paths and compact or expanded work traces change presentation without changing chat state, actual directories or captured tools. **Model token limits** (on by default) shows or hides reported context and output badges in the [model picker](../../providers/models.md); turning it off never changes model choice or discovery. Local saved preferences should apply consistently on reopening; reduced motion and Off retain understandable working states.
