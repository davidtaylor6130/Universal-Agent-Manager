# Themes

Themes select a built-in or custom colour palette for the local interface while preserving contrast, semantic colours and shared control hierarchy. Users can create, clone, edit, import and export supported custom themes; editing a built-in starts a custom copy, and deleting a custom theme must be explicit. Keep theme-editor drafts until save or deliberate discard, validate imported data and preserve the previous palette if persistence fails. Theme selection does not change provider configuration or application behaviour. Every built-in theme defines its own usage token-type colours (input, cache read, cache write, output, reasoning) tuned to its surfaces, and the custom theme editor lists them beside the other semantic colours; a custom theme saved before they existed uses its base's defaults.
