# Themes

Themes select a built-in or custom colour palette for the local interface while preserving contrast, semantic colours and shared control hierarchy. Users can create, clone, edit, import and export supported custom themes; editing a built-in starts a custom copy, and deleting a custom theme must be explicit. Keep theme-editor drafts until save or deliberate discard, validate imported data and preserve the previous palette if persistence fails. Theme selection does not change provider configuration or application behaviour.
