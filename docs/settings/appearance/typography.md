# Typography

Typography configures separate fonts and sizes for interface text, message input, code/diffs and the native terminal view. Each preview must represent the affected surface; updates and Reset typography apply to the local presentation without changing message content or provider settings. Keep choices within supported bounds, retain readable fallback fonts and preserve keyboard reachability and layout at every permitted size.
