# Shell Actions

Shell Actions defines reusable user-configured actions and their ordered groups for workspace or shell integration. Editing, grouping and collapsing must retain drafts; Save applies valid changes and Discard restores saved configuration. Running an action uses its intended workspace, host and selected chat options rather than guessing from the visible folder. Installing an OS integration is distinct from saving an action and must report its actual result.
