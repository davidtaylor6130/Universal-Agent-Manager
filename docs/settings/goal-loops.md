# Goal Loops settings

Goal Loops settings bounds continuing goal work through a maximum iteration count. Provider setup inactivity timeout separately limits setup with no progress; turn output limit bounds one provider turn and excludes startup history. These are different safeguards, not permission to resend delivered input or a guarantee of total response time. Changes must retain valid saved limits and leave failures visible. Current controls offer 1–200 iterations and bounded timeout/output choices; their exact supported values belong in the UI/source rather than duplicated lists throughout the docs.
