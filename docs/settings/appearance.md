# Appearance

Appearance changes the local interface’s theme, typography and motion while retaining the same hierarchy, accessible contrast and usable density. Use shared tokens and primitives so every built-in theme remains coherent. Motion choices scale common timings, and Off or reduced-motion preferences must preserve clear working and completion states without requiring animation.
