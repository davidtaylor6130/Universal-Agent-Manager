# Git

Git integration supports explicitly configured workspace isolation, branches, checkpoints and supported commit or port-to-source actions. Preserve user-owned branches, ignored files and unrelated changes; changing a conversation branch does not itself request a new worktree. Git enablement is separate from SVN tracking and local snapshot choices, and remote operations must execute against the intended remote workspace.

[Local snapshots](local-snapshots.md) · [Workspaces](../../workspaces/workspaces.md).

Automatic isolation prepares a separate worktree for an eligible new chat. Default base branch is a local existing ref (empty means HEAD). A positively verified local Git repository with no initial commit can use the enabled plain-folder snapshot policy to create an initial baseline in UAM-owned storage and isolate from that baseline; UAM does not commit into or change the original repository. Explicit base choices and snapshot opt-outs remain effective. A uniquely owned interrupted journal can resume preparation when its planned artifacts were never created; changed ownership, occupied targets and partial artifacts must be preserved and reported rather than treated as ready.

Pull before first chat conditionally fast-forwards a clean upstream-tracked source. A verified local branch without an upstream continues locally without pulling. Tracked or staged changes and an in-progress Git operation skip this optional pull and allow isolation from a verified committed base, with a non-blocking warning; source changes and operation state remain in the source and are not copied into that committed-base worktree. Dirty source isolation also warns when pulling is disabled or there is no upstream. Failed or uncertain Git validation, invalid explicit bases and other unsafe configured-upstream pulls still report their unresolved step; UAM never configures an upstream or fetches/resets unconditionally. Port methods Merge and Squash stage changes for explicit later commit; Patch applies the exported patch without pretending an upstream publication. Failed preparation/porting preserves unrelated work.
