# Skill library

The library lets users search and group installed skills, pin favourites, inspect content/supporting-file identity, reveal files, edit/create entries and attach a selected skill to the intended request. Imports can come from a provider, file or folder and require a review of valid candidates with explicit Skip existing, Replace existing or Keep separate collision handling. Invalid/unsupported candidates cannot silently replace existing resources. Keep title, maker, group, summary and body drafts until save or deliberate discard; Markdown preview is presentation rather than execution. Confirm destructive removal/overwrite and preserve supporting resources and unrelated files.
