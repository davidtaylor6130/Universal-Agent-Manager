# Change workflow

Before implementation, read the owning feature, parent introduction and applicable architecture/UI rules; find and respect the V5 task owner. Keep changes in the authorized worktree and preserve unrelated work. In the same commit, update affected behaviour agreements, provider capability rows, system relationships and the V5 log. If no documentation change is needed, state why. Report what changed, the checks actually run and remaining limits; implementation, peer/Claude review and user acceptance remain separate. Do not mark Complete without David's specific approval and required review.

[Repository instructions](../../AGENTS.md) own the exact workflow and ownership rules. [Documentation rules](../documentation-rules.md) own page structure. Detailed receipts belong in working notes rather than feature paragraphs.
