# Questions and permissions

Provider questions present the requested choices or supported free-text answers against the correct pending request; permission prompts separately ask whether an action may proceed under the selected safety policy. Do not treat an unanswered question, a closed dialog or expired request as consent. Submitted answers retain their request/chat identity, and a late response must not answer a replacement request or restart unrelated work. Native terminal prompts remain inside the CLI rather than acquiring structured-dialog guarantees.
