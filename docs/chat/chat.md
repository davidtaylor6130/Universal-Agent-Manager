# Chat

A chat is UAM’s durable conversation with its own provider selection, model, agent, workspace, execution environment, history and runtime state. These identities remain distinct: a UAM chat ID is not a provider session ID or a Git branch. Chats can be selected independently in multiple panes and keep their relationship to branches and side chats without sharing unrelated runtime decisions.
