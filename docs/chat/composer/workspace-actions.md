# Workspace actions

Workspace actions operate on the current chat’s workspace, including opening a configured editor or file manager and running configured shell actions. They must use the intended workspace and environment, and unavailable remote actions must be clear. Their available choices are configured under [Editors](../../settings/editors.md) and [Shell Actions](../../settings/shell-actions.md); this menu does not define separate editor or command settings.
