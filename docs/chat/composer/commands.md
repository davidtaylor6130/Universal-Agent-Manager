# Composer commands

Composer slash commands offer UAM actions and supported provider/model choices without confusing local configuration with authored provider input. Show relevant available choices, keep completion keyboard-accessible and distinguish command feedback from an assistant response. Skills selected through discovery retain their attached-resource semantics; a matching label does not establish native slash-command support. Unsupported or failed commands must report their outcome rather than silently submit a different prompt. Commands that compact, branch, change modes or navigate side chats follow the same owning agreements as their visible controls.
