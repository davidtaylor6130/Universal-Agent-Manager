# Motion

Motion explains state and continuity: panels, menus, list changes, disclosure and value changes use purposeful, calm transitions without blocking input or causing layout jumps. Motion is physical and logical: nothing pops in or vanishes; elements enter from an origin and leave back toward it, with selection indicators sliding to the clicked item (the settings sidebar being the reference) and reordered lists gliding to their new positions. Pure opacity animation is for special cases only, such as the long-loading skeleton shimmer showing the app is alive. Working/loading state should visibly indicate progress while animation is enabled and settle when work ends; reduced-motion or Off must still communicate that state without requiring movement. Provider fast mode is unrelated to UI motion speed.

Use `--dur-fast` (120 ms), `--dur-base` (180 ms), `--ease` and `--ease-out-soft`; respect `prefers-reduced-motion`. Appearance → Animation speed selects Default, Fast, Slow or Off through `data-motion` and shared `--dur-*` tokens, persisted as `uam-motion`. New transitions use those tokens rather than fixed timings. Motion Off and the OS reduced-motion preference share one global stop that also settles fixed-duration animations and transitions (spinners and working rings remain visible but still), and fallbacks that keep a still working picture apply to Motion Off as well as the OS preference. The empty-chat composer moves with a transform-based FLIP transition; reduced motion changes position immediately. Shared exit and presence animations change immediately under reduced motion or Motion Off rather than waiting for a 0 ms animation to end, and otherwise stay mounted for the exit length scaled by the selected speed. Usage and Settings leave through this same shared exit presence. The composer's Editing message and side-chat tabs enter and leave with the subagent disclosure motion (a short drop from above with fade, `--dur-enter` in and `--dur-exit` out), matching subagent cards and rows. Panel, menu, settings-selection and list-selection motion animates only transform and opacity: side panels claim or return their space in one step while the panel slides in from, or back under, its rail like a drawer, menus scale in from their anchor and shrink back faster on close, and selected rows change paint only. Nothing animates while idle.
