# Structured chat

Structured chat presents assistant text, reasoning when available, tools and results, questions, permissions and lifecycle state through the common UAM conversation. Providers can use different protocols, but their events must have consistent user meanings. Starting, stopping, errors and interrupted responses must be visible without exposing raw protocol output as conversation text. Antigravity remains outside the structured release scope pending the recorded decision.
