# Provider usage figures

UAM distinguishes per-turn tokens, conversation context, account allowances and aggregated usage history. Show actual figures when the provider exposes them; mark estimates and unknown values clearly rather than treating them as zero. Input, cached input, output and reasoning remain distinct where available, and local/remote scopes must not double-count one event. Account allowance is not the same as context-window capacity.
