# Models

Model discovery and selection belong to the chosen provider and execution environment. Show real advertised or explicitly configured models, retain the selected model during refresh, and distinguish cached choices from confirmed availability. A selection must reach the running or next-started session as appropriate; unavailable models produce an actionable error instead of silently selecting another. Provider/model changes must not leak another chat’s selection.
