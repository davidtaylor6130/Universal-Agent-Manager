# Provider MCP connections

Configured MCP connections must be available to the selected provider on the computer and workspace where it runs, using native configuration or UAM integration as needed. Availability, connection failure and unsupported transports must be explicit. Configuration is applied through provider setup, not pasted into ordinary user messages; secret references must resolve on the executing computer.
