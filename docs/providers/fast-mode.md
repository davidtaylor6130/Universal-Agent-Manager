# Fast mode

Fast mode means a provider or model’s actual speed/service-tier option, not faster UI animation or a promise of response latency. Offer it only when supported, apply and persist the selected tier, and make any known difference in usage or charging understandable. Where no equivalent exists, record the capability as unavailable rather than presenting a cosmetic speed toggle.

A native preference request is separate from the effective tier. Show pending or activating changes until the provider confirms them, preserve advertised disabled choices and their reasons, and never reset a native preference merely by opening settings or resuming a chat.
