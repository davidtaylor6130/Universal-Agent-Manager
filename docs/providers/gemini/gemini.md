Native capabilities depend on the installed CLI, selected model and execution environment; shared UAM routes do not imply that every native variant is supported.

Named thinking pins the selected concrete model rather than following native alias upgrades or substitutions; a retired preview can therefore fail where Default follows native routing. Each launch captures the executing host’s native trust/settings state and checked CLI version, so later TUI trust changes or external CLI upgrades require a fresh launch/check. Named thinking requires a directly resolved Gemini executable and fails explicitly when IDE or workspace trust cannot be established safely; Default remains available to clear an unsupported saved choice.

Native history discovery follows the executing CLI’s home: a configured `GEMINI_CLI_HOME` replaces the home directory and history remains under its `.gemini` directory; otherwise the platform user home applies. Registry and workspace ownership evidence must agree; imported parent files and exact child reads cannot cross the selected project or parent through a path alias. An unrelated rejected project must not hide an independently attested workspace, while contradictions or ambiguity affecting the selected workspace reject the read. UAM does not use the undocumented `GEMINI_HOME` override for this history route. Controller-local inline media follows the shared [discovery cleanup ownership](../../chat/native-imports.md#discovery-media-lifetime) agreement; scan-wide admission exhaustion reports a discovery error, and focused macOS native fixtures verify cleanup and that refusal, while live provider, Windows/SSH and user acceptance remain pending.

Gemini CLI records its generated `<session_context>` environment preamble as the first `user` row of each session file. The preamble contains the date, OS, temporary directory, workspace tree and loaded server instructions. The row carries Gemini's fixed environment-context ID, and ACP `session/load` replays it as a user chunk. That row is model context rather than a user turn, so native import, refresh, child history, default titles and title-generation transcripts omit it, and a session holding only the preamble is an empty placeholder rather than an importable chat. UAM chats saved before this rule are not rewritten; they keep their stored copy until the native conversation advances, and a saved preamble-only chat whose native session no longer exists must be deleted manually. Only the first row qualifies, and only when it has that ID, a single text part and Gemini's exact opening and closing markers. Typed `<session_context>` text, including a pasted copy of the whole preamble, remains visible user history. ACP replay chunks never become chat messages. Focused native fixtures shaped from Gemini CLI 0.65.0 session files cover this, while live provider and user acceptance remain pending.

When a launch needs Windows native-home resolution, UAM uses `USERPROFILE` and then the OS profile lookup; a required settings or trust location that cannot be resolved fails explicitly rather than guessing another profile. Equivalence with Node’s profile-token lookup in restricted service accounts and long-profile-path environments remains unverified.

## Managed initial binding

A local read-only UserRoot initial child with explicit routing and a named model may retain a binding only when its owned native initialization identifies Gemini CLI 0.55.1 or 0.64.0 and its correlated raw ACP `session/new` reply supplies a canonical session UUID, an exact selected model advertised once, and current Plan mode advertised once. Setup selection alone does not establish execution: the correlated completed `session/prompt` result must report that same sole model in native per-model usage, with positive, valid counters consistent with its totals. Actual input, a subsequent canonical save, completed result and confirmed process reaping remain necessary. Missing, malformed, mixed or contradictory proof preserves the existing unbound one-shot. Nonempty/invalid configuration options, native configuration changes and Gemini’s `[MODE_UPDATE]` notification permanently withhold this binding even if matching values return; text can revoke proof but never create it. The workspace remains the captured owned local launch/setup scope. The [versioned native-source contract and remaining matrix](../../reference/architecture/provider-sessions.md#managed-initial-binding-scope) record the inspected native-source grammar, focused hermetic UAM native verification and remaining live limits: same-child Gemini continuation, other principals, nesting, SSH and restarted execution ownership remain incomplete, with Windows and David’s acceptance pending.
