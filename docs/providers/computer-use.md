# Provider computer use

Computer use can be delivered by a provider-native controller or UAM’s shared controller. The selected route must be explicit, must not accidentally enable both, and must preserve the user’s enablement and permission choices. A provider lacking a native controller should use UAM where available; local-only UAM support does not establish SSH computer-use support. Provider-native controls must not be described as having UAM’s target grants or stop guarantees.
