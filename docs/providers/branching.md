# Branching

Branching creates a separate conversation from a chosen point without changing the original. UAM owns the branch relationship and supplies the required context when native branching is unavailable; compacted context must stay compacted rather than replaying superseded history. Conversation branching and Git branch/worktree isolation are separate choices. An empty chat should create a new chat instead of a historical branch.
