# Reasoning

Reasoning controls expose only effort levels actually supported by the selected provider and model, and the saved choice must be applied to execution. When a provider emits displayable reasoning or summaries, UAM renders them separately from ordinary replies with consistent disclosure. An empty choice remains provider Default when no actual default level is advertised, and provider-wide defaults do not adopt an unrelated chat’s selected model. Do not manufacture hidden reasoning or imply that an unsupported effort setting has taken effect.

Launch-configured reasoning uses the selected concrete model and a checked version from the same execution host. An explicit choice is captured in immutable host settings even when central instruction setup is disabled; changing it requires an idle runtime restart. Routed aliases and unverified model/version combinations expose only Default, and Default leaves the native setting unmodified.
