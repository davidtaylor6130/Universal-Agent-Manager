# UAM tool connection

The built-in UAM MCP connection exposes approved UAM capabilities such as questions, skills and goals to compatible structured sessions. An enabled configuration, prepared resource bundle and actual observed connection are different states. Enabled pre-binding startup is setup in progress, not a missing connection or observed handshake; an unknown observation never establishes availability or failure. A ready or previously bound session with missing capability and a recorded setup failure remain actionable rather than being hidden by running work. Missing/failed connection warnings offer Enable UAM connection, View settings or Continue without it; continuing dismisses the warning for the relevant session rather than pretending tools work. Enabling setup applies on the next provider start without interrupting current work. A stale response must not change another chat or host, and built-in Computer Use retains its separate enablement/target consent.

For managed children, the shared [active-turn result wait](../chat/subagents.md#active-turn-result-wait) reads one exact owned run through `agent_wait {runId}`. A completed result belongs to the original tool call; a bounded still-running outcome is explicit and permits another wait on that same run. It neither creates replacement work nor cancels the child, and it cannot resume an ended parent turn. Configuration, tool exposure and one observed invocation remain distinct from a provider's actual long-call deadline and live local/SSH support. Canonical runtime and provider-specific verification remain pending.

Delegation results additionally report `resultDelivery` as `cooperative-only`, `automatic-pending` or `held`, with a fixed reason. `automatic-pending` is a conditional same-live-parent route described in [parent result continuation](../chat/subagents.md#same-live-parent-result-continuation), not proof of native input acceptance or parent consumption. This source-integrated route preserves ordinary delegation approvals and does not grant permission from a model-supplied option or a saved record.
