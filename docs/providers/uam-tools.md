# UAM tool connection

The built-in UAM MCP connection exposes approved UAM capabilities such as questions, skills and goals to compatible structured sessions. An enabled configuration, prepared resource bundle and actual observed connection are different states. Missing/failed connection warnings offer Enable UAM connection, View settings or Continue without it; continuing dismisses the warning for the relevant session rather than pretending tools work. Enabling setup applies on the next provider start without interrupting current work. A stale response must not change another chat or host, and built-in Computer Use retains its separate enablement/target consent.
