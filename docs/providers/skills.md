# Provider skills

A selected skill includes its instructions and supporting scripts, references and assets, not just a name or isolated Markdown excerpt. UAM makes those resources usable on the executing computer, including SSH, when a provider has no native skill mechanism. Explicitly attached skills remain part of the authored request; installation and discovery alone must not be presented as proof that a model used the skill.
