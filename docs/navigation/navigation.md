# Navigation and keyboard actions

Main navigation switches between chats, Usage and Settings while retaining each surface's drafts and selection; opening a tool panel must not silently send input or stop a provider. Chat-selector and tool-panel resizing preserves usable panes, and overlays take precedence over background shortcuts. Shared shortcuts use Command on macOS and Control elsewhere: N creates a chat, K focuses search, comma opens Settings, B toggles the sidebar, Shift+J moves to attention and Shift+L focuses the active input. Agent cycling has its own configurable shortcut. Respect text entry, native terminal input and modal focus, restoring focus to the initiating control when appropriate.

On macOS and Windows, window controls share the app-level strip with the split-layout actions; empty strip space drags the window. macOS uses its native traffic lights, and Windows places Minimize, Maximize/Restore and Close at the upper right. Chat search stays inside the sidebar, and each split pane keeps its own title and controls below the strip. Settings, Usage and tool panels retain window controls without taking over a chat header. If the native window does not provide integrated controls, UAM keeps the system title bar and draws no strip, so content is never pushed below a second title area.
