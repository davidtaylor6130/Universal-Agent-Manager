# Updates

Updates distinguishes the desktop application, provider CLIs and remote helpers, including installed/latest version, available action and failed checks. Users can check manually or enable automatic checks; checking is not installation. Provider updates must disclose running sessions and require the appropriate stop decision rather than disrupting work silently. Application releases may open a release/download or manual instructions rather than promise in-place installation. Remote helper activation retains its own compatibility and active-work checks. Surface failures and uncertain versions, retain release information and distinguish dismissing an update notice from cancelling or completing installation.
