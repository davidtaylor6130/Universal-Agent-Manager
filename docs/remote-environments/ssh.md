# SSH execution

SSH execution runs providers and workers through a verified UAM helper on a configured OpenSSH alias, keeping authentication and host verification with OpenSSH. Reconnect must recover the correct process and output without replaying delivered prompts. Instructions, skills, attachments and MCP configuration must be usable on that computer. Helper updates must respect active work and preserve recovery; local editor actions and remote desktop computer use are not implied by SSH support.

**Implementation: Partial.** Linux x86-64/ARM64 and Windows x86-64 helper routes exist; macOS remote-helper packaging and various live/provider combinations remain unverified. Commands UAM runs on a remote Windows host use built-in Windows PowerShell 5.1 (`powershell.exe`) and 5.1-compatible scripts; a per-host PowerShell choice is not implemented, and the [Editors](../settings/editors.md) Terminal shell choice applies only to terminal windows opened on a Windows controller. See [architecture](../architecture/execution-hosts.md), [provider checklists](../providers/providers.md#provider-checklists) and [build flags](../build-flags.md).
