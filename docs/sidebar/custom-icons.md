# Custom icons

Chats, workspaces, hosts and collections can have a persistent custom icon: a searchable Lucide symbol, emoji or supported PNG image. An icon changes presentation, not provider, execution host or resource identity; provider/host glyphs remain fallbacks where no custom choice applies. Changes and reset/removal target the intended resource and must preserve the existing value if saving fails. Keep controls and icon-only states accessible without relying on the chosen picture as the only identity label.
