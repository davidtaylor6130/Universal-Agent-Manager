# Waking chats

A snoozed chat returns to Active Chats when its wake time expires or the user chooses Unsnooze, including an older settled conversation that would otherwise stay quiet. Pending runtime attention can surface before the scheduled wake time. Wake-up changes attention organisation; it must not automatically send a prompt, resume a held queue or create a provider turn.
