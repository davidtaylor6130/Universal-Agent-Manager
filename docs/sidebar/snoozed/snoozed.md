# Snoozed chats

Snoozing parks a chat’s attention until a chosen future time while preserving its conversation, pinning and workspace membership. The wake time remains readable without colliding with row actions, and users can wake a chat explicitly. Pending approvals, input requests or new work requiring attention must not disappear behind snooze; snoozing is not a provider pause or shutdown action.
