# Chat search

Search finds saved conversations by their catalogue information, with an explicit Search contents option for matching messages. Provider and state filters combine with the search without changing chat history or ownership; clearing filters restores the catalogue view rather than deleting results. Content hits must open the correct conversation/message, and stale asynchronous results must not replace a newer query. Deep search must respect hidden/deleted or discarded content rules rather than resurrecting excluded history, and indicate loading, empty or failed search honestly.
