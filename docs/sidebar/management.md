# Chat and workspace actions

Chat rows offer rename, regenerate/cancel title generation, copy details, pinning, snooze, collections and explicit deletion; actions target the chosen chat or disclosed branch family, not whichever row becomes selected during background work. A title worker changes only the title and must not overwrite a newer manual rename. Multi-selection, drag/drop and ordering change organisation while preserving conversation identity. Workspace menus separately offer naming, host/directory choices and native-session review; memory lives in [Settings → Memory Store](../memory/store.md). Deletion confirms affected chats/families/workspace entries, reports real cleanup progress and retains failures; deleting a workspace entry does not delete the user's underlying directory. Reusing an existing owned worktree for a new chat is distinct from creating another isolated worktree. Every chat row menu, in Active Chats, Pinned and All Chats, starts with **New chat in this workspace** whenever the chat belongs to a workspace: it opens the same New chat dialog as the workspace header's New chat, with that workspace and its execution host preselected, and has no separate creation path. **New chat in this worktree** sits beneath it and is available only for a local, writable chat in a UAM Git worktree and is otherwise shown disabled.

Selected chat rows, workspace headers and collection headers use the shared Settings selected-item style (`.uam-selected-item`: `--accent-dim` tint, primary text and one straight 3 px accent line inset inside the rounded corners, with a system Highlight outline and line in forced-colours mode); chat rows also show the bulk-selection check mark, while the open chat keeps its lighter active tint without a line and keyboard focus keeps its separate focus outline. A Shift-click multi-selection of chat rows, workspace headers or collection headers turns the row menu, the Delete key and a selected row's hover actions (pin, wake, snooze, done) into actions on every selected row. Chats support deletion, pinning or unpinning, title regeneration, icons, copying names/IDs/paths/branches/native session IDs, snooze/wake, marking done and collection moves; workspaces support collection moves, icons and deletion; collections support icons and deletion. Actions with a single target—rename, a new chat in a worktree or workspace, native-chat review, host icons and a collection's New collection inside, Move to collection and Move to top level—stay visible but unavailable, keyboard reachable and described as “Not available for multiple selection — select a single chat” (or workspace or collection); they never act on just the clicked row. Deletion asks once, counting selected rows and their branches. Every sidebar delete (one or several chats, workspaces or collections) uses the same sidebar delete confirmation built on ConfirmDialog: its title and accessible name state the item type and count (and the name for a single item), the message states what is deleted with them (related branches, the chats inside a workspace) and that it cannot be undone, followed by case-specific consequences such as workspace directories staying on disk or a collection's workspaces remaining; a single item reads the same whether deleted from its menu or as a one-item selection, and contents are omitted when there are none. Cancel comes first and takes focus, Escape and the backdrop cancel while idle, focus returns to the originating chat or workspace row on close, and a busy delete announces its progress through a polite status region and cannot be dismissed. Each chat row's branch family or workspace is admitted separately: refused rows keep their running-runtime, saving and ownership safeguards and stay selected, the rest proceed, and every refusal or failure is reported by name through the shared notification path. Chat, workspace and collection row menus all use the shared sidebar menu row pattern: 14px icons on every item, a red Delete item and the elevated panel style; the collection menu also separates Delete with a divider.
