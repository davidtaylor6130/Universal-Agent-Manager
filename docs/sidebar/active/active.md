# Active Chats

Active Chats brings running conversations, new completed work and chats needing attention into a distinct section above the workspace tree. Keep its collapse control, status counts, Done, Snooze and Clear all actions. Clearing attention is organisation, not permission to delete history or stop a running provider. A branch family must reflect relevant child activity without attributing another family’s state to the selected chat.

Subagent chats do not appear as separate Active entries; their main chat remains the attention and return destination, with children available beneath it in [All Chats](../all-chats/all-chats.md).
