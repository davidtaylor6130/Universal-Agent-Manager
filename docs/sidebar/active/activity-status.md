# Activity status

Status distinguishes running work, waiting for permission or input, completion, interruption, failure and unknown activity. Use actual runtime evidence; Connected must not pretend to mean Ready or Busy when a native terminal cannot expose that distinction. Working indicators explain real work and settle when it ends, while attention indicators remain available until acknowledged or snoozed.
