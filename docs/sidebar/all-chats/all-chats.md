# All Chats

All Chats is the durable catalogue of conversations rather than a list of currently running processes. Users can find chats through their names, workspace grouping and branch relationships regardless of attention state. Filtering and organisation must not mutate conversation history, manufacture missing sessions or hide a saved chat merely because its provider is stopped.

Subagent families start collapsed beneath each parent, with an explicit expand/collapse control. Expanded children use ordinary single-line rows with a robot icon and a work-purpose title; the agent definition is secondary metadata. Search can reveal matching children without changing the chosen collapse preference, and selecting a different native descendant opens its ancestors while ordinary updates respect a user’s collapse. The list updates automatically without a Refresh subagents control; opening a row displays only the child conversation and keeps a fixed parent return control at the top, following the [subagent navigation agreement](../../chat/subagents.md#catalogue-and-navigation). Source is integrated; native compilation, fresh Claude Review, visual verification and user acceptance remain pending.
