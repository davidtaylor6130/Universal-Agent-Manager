# File inspection

File inspection reads a referenced file in the selected chat's actual workspace and execution environment and shows its resolved identity, content and line numbers without modifying it. A path chip, diff or recorded edit can open the inspector, but current file content is distinct from an old patch or attachment snapshot. Copying uses the displayed content; a request from an obsolete chat or host must not replace the current inspection. Missing, unreadable, unsupported, binary or bounded/truncated content must be described honestly rather than rendered as a complete empty file.
