The provider checklist labels **Implemented** only identify an existing source route. Partial and Needs verification rows deliberately retain limits from the base evidence; a full audit must exercise the relevant native CLI, platform and remote combinations.

Independent account allowances use `src/common/usage/account_allowance_service.*`, `account_allowance_fetcher.*`, `claude_account_allowance.*`, `google_account_allowance.*` and the credential-store reader `account_credentials.*` over `src/common/platform/credential_store.*`; the bridge is `src/cef/usage_handlers.cpp` and the frontend uses `UI-V2/src/services/providerAllowances.ts` with `useProviderAllowances.ts`. Native import content eligibility is in `src/core/native_import_content.h` with focused coverage in `tests/empty_native_import_tests.cpp`.
