# Provider sessions

Provider adapters translate ACP, app-server and other supported structured protocols into one UAM lifecycle and message model. Native terminals use a separate PTY path. Shared UAM services provide product features across providers, while adapters own launch/protocol handling and native session identity. Start, cancel, exit, resume and permission results must stay with the owning chat, including concurrent and remote instances.
