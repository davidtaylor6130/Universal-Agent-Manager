# Memory architecture

Memory services extract and recall optional durable knowledge stored as local Markdown resources under global or effective-workspace ownership. Policies govern both recall and publication, including when asynchronous work finishes after settings change. Memory is bounded contextual input, not a replacement for provider conversation history, central instructions or skills.
