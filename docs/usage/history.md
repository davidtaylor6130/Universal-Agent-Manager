# Usage history

Historical usage offers Cost and Tokens views for a selected time window, this computer, a specific host or All machines. Provider filters affect the shown totals, chart and model/time breakdown together; changing them must not mix incompatible snapshots. Token categories remain distinct where reported, models and service tiers retain their identity, and the Time view identifies its time basis. Refresh preserves usable prior data while loading and discloses stale, incomplete, unavailable or failed machine collection. Missing sources are not zero usage, duplicate/fork records must not inflate totals, and diagnostics should explain known coverage gaps. Limits is a separate account view and does not acquire historical meaning from the selected history period.
