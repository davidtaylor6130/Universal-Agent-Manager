# Usage costs

Cost totals and charts combine reported charges with estimates while keeping their provenance clear. Missing prices must retain a visible unpriced-token count, disclose excluded tokens and label the partial total Known cost; unknown charges are not zero-cost usage. Provider, model and total cost amounts name their basis: Reported for provider charges, Estimated for API list-price estimates (which are not a bill), Reported + estimated when both contribute and Known cost when some tokens are unpriced. Price overrides change estimates without rewriting observed token counts. Cached machine history can preserve known totals while marking collection incomplete, and local or remote records must not be counted twice.
